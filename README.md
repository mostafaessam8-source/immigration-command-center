# Immigration Command Center

Interactive Arabic RTL roadmap for Canada and Australia immigration journeys, from eligibility assessment to first salary.

## Features
- Canada / Australia switch
- Expandable roadmap steps
- Per-step status tracking
- Automatic progress percentage
- Next Best Action
- Official reference links
- Local browser persistence
- Mobile responsive

## GitHub Pages
Publish from the main branch root using Settings → Pages → Deploy from a branch → main / root.
